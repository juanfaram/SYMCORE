# Omega Root Invariants

I1 Semantics > Performance.
I2 Evidence > Narrative.
I3 UNKNOWN != FALSE.
I4 Failure(A) does not imply Failure(T); Failure(T) does not imply Failure(H).
I5 Search != Certification.
I6 Knowledge counts only when it improves future decisions.
I7 Architecture requires measured pain.

These invariants are root constraints. Other architecture may evolve.
